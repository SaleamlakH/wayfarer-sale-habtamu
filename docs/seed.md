# Wayfarer Seed Data

## 1. Overview

This document describes the initial dataset used to populate the Wayfarer
database during development.

The seed data is designed to satisfy the data requirements while providing 
enough variation to demonstrate the application's core functionality.

The dataset includes:

- 3 users for the acting-as user switcher.
- 5 categories for filtering places.
- 10 places across the available categories.
- Reviews with different ratings and review counts.
- Tour slots with different capacities.
- Existing bookings to demonstrate different slot availability states.

The place descriptions, review texts, and other sample content are
illustrative placeholders created for development and testing. They should
not be interpreted as actual visitor feedback or verified information
about the listed places.

### Identifier note

The numeric `ID` values in the tables below are documentation references
used only to express relationships within this document. They are not
inserted as record identifiers. In the actual seed, every record ID is
generated by Prisma using the schema's `@default(uuid())`, and the numeric
references are mapped to those generated IDs when related records are
created.

## 5. Reviews

Reviews are distributed across all ten places, with different review
counts and ratings.

This distribution is intentional. It provides data for demonstrating
the ranking functionality and evaluating how the ranking formula accounts
for both average ratings and the number of reviews.

In particular, the dataset includes:

- A place with only one review and a 5-star rating.
- Places with two reviews.
- Places with three reviews.
- Different rating averages across places.

This ensures that places with very few reviews can be compared against
places with more reviews, demonstrating why a simple average is not
sufficient for the top-rated sorting functionality.

## 8. Model Coverage

The seed data uses the following models and their defined fields:

| Model | Fields |
|---|---|
| Category | id, name |
| User | id, name |
| Place | id, name, category_id, description, opening_hours |
| Review | id, place_id, user_id, rating, body, created_at |
| TourSlot | id, place_id, starts_at, capacity |
| Booking | id, slot_id, user_id, seats, created_at |

No additional attributes are introduced beyond the defined models and
the Category model.

Every `id` value is generated by Prisma's `uuid()` default. The numeric
IDs shown in this document are reference labels only.

## 9. Assignment Requirements Coverage

The prepared dataset supports the following assignment requirements:

| Requirement | Seed Data Coverage |
|---|---|
| Seed three users | Three users are provided. |
| Seed approximately ten places | Ten places are provided. |
| Provide categories | Five categories are provided. |
| Provide reviews for places | All ten places have reviews. |
| Include a place with 1–2 reviews | Multiple places have only one or two reviews. |
| Demonstrate ranking behavior | Different review counts and ratings are provided, including a single 5-star review. |
| Provide tour slots | Six tour slots are provided across three places. |
| Demonstrate remaining seat calculations | Bookings cover almost-full, fully-booked, available, and unbooked slots. |

The seed dataset provides the initial records required to demonstrate
the application's main functionality. It does not replace the automated
tests required for ranking correctness and concurrent booking safety.
